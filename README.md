# Quick File Organizer

A lightweight Python utility designed to automate local file sorting and directory cleanup for developers and power users.

## Features
- Automatically categorizes files into Images, Documents, Archives, Scripts, and Others.
- Clean and minimal async-ready file routing logic.
- Zero external dependencies beyond standard Python libraries.
